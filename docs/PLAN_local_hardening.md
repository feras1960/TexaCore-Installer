# 🔐 خطة تحصين النسخة المحلية (self-hosted) — لمراجعة فابل

> **الحقيقة الحاكمة:** النسخة محلية؛ المستخدم يملك الجهاز + قاعدة البيانات + الكود.
> ⇒ **المنع المطلق مستحيل** (حال كل برمجيات self-hosted). الهدف الواقعي: (1) إفشال
> الكسر العابر/المتوسط، (2) جعل كلفة الكسر > كلفة الرخصة، (3) كشف التلاعب عبر التلمتري.
> الحلّ الوحيد للحماية المطلقة = تنفيذ الميزات المقيَّدة على الخادم (SaaS) — يناقض قيمة self-hosted.

## نموذج التهديد (الحالي — مُتحقَّق من الكود)
| التهديد | الحالة الآن |
|---|---|
| تعديل `license.dat` | ✅ محمي (AES-256-GCM + HMAC + ربط الجهاز) |
| نسخ الرخصة لجهاز آخر | ✅ محمي (بصمة serial+UUID) |
| إلغاء/تعليق سحابي | ✅ نبض 30ث يقفل فوراً |
| **تعديل القاعدة مباشرة** (`UPDATE tenant_subscriptions`) | ❌ مفتوح (trust + RLS off) — يُصحَّح عند المزامنة فقط |
| **تزوير رخصة** | ❌ الأسرار `_k1/_k2` مشحونة نصّاً في JS ⇒ يمكن اشتقاق المفتاح والتزوير |
| **تراجع الساعة** | ❌ الانتهاء يُفحص بالساعة المحلية ⇒ يمدّد التجريبية دون اتصال |
| تقييد الواجهة | ⚠️ تجميلي (قابل للتجاوز بتعديل JS أو ضرب postgREST) |
| عرض الحالة | ⚠️ الرخصة تعرض enabled_modules قديمة ≠ الباقة الفعلية |

## المراحل

### المرحلة 1 — مزامنة الحالة + مكاسب نزاهة رخيصة (محلي، بلا مقايضات) ⭐ أولاً
- **1أ) مزامنة الحالة الفعلية:** عند `syncActivePlan`، اكتب موديولات/حدود **الباقة الفعلية** إلى `license.dat` ولوحة `/saas/licensing` ⇒ اللوحة تعرض «الوحدات المفعّلة = 22 موديول professional» لا [مبيعات، مشتريات] القديمة. (يعالج ملاحظتك مباشرة.)
- **1ب) إعادة فرض دورية:** فرض `plan = license-tier` كل ~60ث (لا نبض فقط) ⇒ أي تعديل يدوي للقاعدة يُصحَّح خلال ثانية.
- **1ج) حارس تراجع الساعة:** خزّن طابعاً زمنياً **تصاعدياً** (last-seen) موقّعاً؛ إن كانت الساعة < last-seen − هامش ⇒ علِّم تلاعباً ⇒ افرض تحقّقاً سحابياً/اقفل التجريبية. يمنع تمديد التجريبية دون اتصال.
- **الأثر:** يعالج العرض + يغلق الثغرتين الرخيصتين (تعديل القاعدة السريع + الساعة). **بلا مقايضات، كله محلي.**

### المرحلة 2 — توقيع رخصة لا-تماثلي (يغلق ثغرة التزوير) ⭐⭐ الأعلى قيمة
- استبدل HMAC المتماثل (مفتاحه مشحون) بـ**Ed25519/RSA**:
  - الخادم يحمل **المفتاح الخاص** ويوقّع كل رخصة (المستوى/الانتهاء/البصمة/الموديولات).
  - العميل يحمل **المفتاح العام** ويتحقّق فقط.
  - ⇒ **لا يمكن تزوير رخصة حتى مع كامل الكود** (لا مفتاح خاص). يُقبل فقط ما يصدره الخادم.
- دعم مزدوج (v2 قديم + v3 جديد) أثناء الانتقال.
- **المقايضة:** إعداد مفاتيح خادمية + نقطة إصدار رخصة. جهد متوسط. **أكبر مكسب أمني منفرد.**

### المرحلة 3 — إغلاق قاعدة البيانات (أكثر تدخّلاً)
- **3أ) كلمة مرور للقاعدة** بدل trust (مشتقّة من البصمة، كالرخصة) ⇒ `psql` العابر يفشل. *(الماهر يستخرجها من الكود، لكن يوقف التعديل التافه.)*
- **3ب) دور تطبيق غير-superuser + جدول `license_state` محمي + تريغر يرفض باقة تتجاوز سقف الرخصة.** إنفاذ حقيقي على مستوى القاعدة.
  - **قيد جوهري:** PG يعمل بمستخدم النظام نفسه ⇒ المستخدم يتصل كـsuperuser ويعطّل التريغرات. الإنفاذ الحقيقي يتطلب تشغيل PG بمستخدم OS منفصل — صعب على جهاز مملوك.
- **رأيي:** 3أ يستحق؛ 3ب دفاع-في-العمق لكنه ليس مطلقاً (يبقى تجاوز superuser).

### المرحلة 4 — فحص اتصال إلزامي للمدفوع (ردع + تلمتري)
- إن مرّت N يوماً بلا نبض ناجح (مهلة سماح) ⇒ المدفوع/التجريبي يقفل أو ينزل للمجاني. يجعل القرصنة دون اتصال محدودة زمنياً. (موجود جزئياً: نبض + landTrialToFree — نُنظّمه بمهلة صريحة.)
- **المقايضة:** يتطلب اتصالاً دورياً (مقبول؛ المستخدم دون اتصال دائم يحتاج مهلة أطول/رخصة أوفلاين).

### المرحلة 5 — نزاهة الكود / مكافحة العبث (اختياري، عائد متناقص)
- تفعيل **asar** (معطّل حالياً) + asarUnpack للـbinaries ⇒ يوقف تعديل JS العابر (ليس تشفيراً؛ الماهر يفكّه).
- تصغير/تعتيم license-guard + main. اختيارياً نقل التشفير لموديول native.
- **المقايضة:** asar عُطّل لأن ثنائيات postgres تحتاج فكّاً — نحتاج asarUnpack. جهد متوسط، عائد متواضع.

## رأيي (الأولوية)
1. **المرحلة 1 الآن** — رخيصة، بلا مقايضات، تُصلح العرض وتغلق الثغرتين السهلتين.
2. **المرحلة 2 تالياً** — أعلى قيمة؛ تغلق التزوير نهائياً. تستحق الجهد الخادمي.
3. **3أ (كلمة مرور القاعدة)** — تستحق. **3ب (سقف التريغر)** — دفاع إضافي، بلا إفراط.
4. **المرحلة 4** — نفّذها للمدفوع (ردع + كشف).
5. **المرحلة 5** — اختياري؛ فعّل asar لمقاومة التعديل العابر، وتجنّب التعتيم الثقيل.
6. **اقبل المخاطرة المتبقية:** مستخدم ماهر مصمّم على جهازه سيتجاوز (فكّ asar، تعديل JS، PG كـsuperuser) — حال كل self-hosted. الواقعي: القرصنة العابرة/المتوسطة تفشل، والإساءة تُكشف سحابياً، والكلفة تفوق سعر الرخصة لأغلب الناس.
